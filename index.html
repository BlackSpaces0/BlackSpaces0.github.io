Ciberseguridad en español RutaGlosarioReferenciasAcerca

Aprende ciberseguridad desde cero, en español.

Una ruta ordenada, un glosario con palabras sencillas y hojas de referencia para tener a mano. Cada tema explica qué es y para qué sirve.

Todo lo que aparece aquí se debe practicar solo en equipos propios, en laboratorios de práctica o con permiso por escrito.

Ruta de aprendizaje

Sigue el orden. Cada paso te prepara para el siguiente. Con sesiones cortas y constantes avanzas más que con una maratón.

  1. Redes

    Cómo se comunican los equipos: direcciones IP, puertos, DNS y protocolos como HTTP y SSH.

    Sirve para entender qué se ataca y qué se protege.

  2. Linux y la terminal

    Moverte por carpetas, leer archivos, manejar permisos y procesos.

    Sirve porque casi todas las herramientas de seguridad corren en Linux.

  3. Seguridad web

    Las vulnerabilidades más comunes: inyección SQL, XSS e IDOR.

    Sirve para encontrar y corregir fallos en aplicaciones web.

  4. Herramientas básicas

    Nmap para escanear, Burp Suite para analizar tráfico web, Wireshark y tcpdump para ver paquetes.

    Sirve para pasar de la teoría a la práctica.

  5. Práctica guiada

    Laboratorios legales como Hack The Box (Starting Point y Academy) y OWASP Juice Shop.

    Sirve para practicar sin riesgo y sin tocar sistemas ajenos.

  6. Defensa y respuesta a incidentes

    Endurecer sistemas, revisar registros y actuar cuando algo sale mal.

    Sirve para proteger y para investigar, no solo para atacar.

Glosario

Palabras que vas a escuchar todo el tiempo, explicadas sin tecnicismos.

Vulnerabilidad
Qué es: un fallo en un sistema o programa. Para qué importa: es la puerta por la que alguien podría entrar o hacer daño.
Exploit
Qué es: el método o código que aprovecha una vulnerabilidad. Para qué importa: explica por qué conviene actualizar el software.
CVE
Qué es: un número único que identifica una vulnerabilidad conocida. Para qué importa: permite buscarla y saber si te afecta.
Phishing
Qué es: un engaño, casi siempre por correo o mensaje, para que entregues datos o hagas clic en un enlace falso. Para qué importa: es la forma de ataque más común.
Ransomware
Qué es: un programa que cifra tus archivos y pide dinero para devolverlos. Para qué importa: las copias de seguridad son la mejor defensa.
Malware
Qué es: cualquier programa hecho para dañar o espiar. Para qué importa: incluye virus, troyanos y ransomware.
Firewall
Qué es: un filtro que decide qué conexiones entran y salen. Para qué importa: bloquea tráfico que no debería pasar.
Autenticación en dos pasos (2FA)
Qué es: pedir algo más que la contraseña, como un código en el celular. Para qué importa: aunque roben tu clave, no pueden entrar.
Hash
Qué es: una huella única que se calcula a partir de un dato. Para qué importa: sirve para guardar contraseñas y comprobar que un archivo no cambió.
OSINT
Qué es: investigar usando solo información pública. Para qué importa: es el primer paso de muchas investigaciones.
Red team y blue team
Qué es: el red team simula ataques y el blue team defiende. Para qué importa: juntos mejoran la seguridad de una organización.
DFIR
Qué es: análisis forense digital y respuesta a incidentes. Para qué importa: permite saber qué pasó y contenerlo.
Hardening
Qué es: reforzar un sistema quitando lo innecesario y ajustando su configuración. Para qué importa: reduce los puntos por donde pueden atacarlo.

Hojas de referencia

Comandos frecuentes con una línea que explica qué hace cada uno.

Antes de escanear: usa Nmap solo en tu red, en laboratorios de práctica o con autorización escrita. Escanear equipos ajenos puede ser ilegal.

Nmap

Escanea una red para ver qué equipos están conectados y qué puertos tienen abiertos.

nmap -sn 192.168.1.0/24Descubre qué equipos están activos en la red, sin escanear puertos.
nmap 192.168.1.10Escanea los 1000 puertos más comunes de un equipo.
nmap -sV 192.168.1.10Detecta qué servicio y versión corre en cada puerto abierto.
nmap -sC -sV -oN resultado.txt 192.168.1.10Usa scripts básicos, detecta versiones y guarda el resultado en un archivo.
nmap -p- 192.168.1.10Revisa los 65535 puertos. Tarda más, pero no deja nada fuera.

Linux: terminal básica

Los comandos que más vas a usar en Kali y en cualquier servidor.

pwdMuestra en qué carpeta estás.
ls -laLista archivos, incluidos los ocultos, con sus permisos.
cd /ruta/carpetaEntra a otra carpeta.
cat archivo.txtMuestra el contenido de un archivo.
grep "texto" archivo.txtBusca una palabra dentro de un archivo.
chmod 600 archivoDeja el archivo legible solo para su dueño.
ip aMuestra las direcciones IP de tus interfaces de red.
ss -tulpnMuestra qué puertos tiene abiertos tu equipo y qué programa los usa.
