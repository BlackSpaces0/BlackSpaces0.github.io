# Reportar un problema de seguridad

No publiques detalles explotables, credenciales, datos personales ni evidencia sensible en un issue público.

Usa la opción **Report a vulnerability** de la pestaña **Security** de GitHub si está habilitada para este repositorio. Si no aparece, contacta de forma privada a los mantenedores mediante GitHub y comparte solo la información necesaria para coordinar una divulgación responsable.

FOXSEC es material educativo. No pruebes el sitio ni los recursos enlazados de forma que afecte a otras personas o servicios.
