# Código de conducta de FOXSEC

FOXSEC es un espacio comunitario para aprender y colaborar. Participa con respeto, paciencia y buena fe, sin importar la experiencia, identidad, idioma o forma de aprender de cada persona.

Se espera que quienes participan:

- Sean amables y constructivos al dar comentarios.
- Acepten correcciones y diferencias de criterio con respeto.
- Protejan la privacidad: no publiquen datos personales, credenciales ni información privada.
- Mantengan las conversaciones enfocadas en el aprendizaje y el proyecto.

No se permite el acoso, la discriminación, las amenazas, la humillación, el spam ni promover pruebas contra sistemas sin autorización. El equipo mantenedor puede editar o retirar contenido que incumpla estas reglas y limitar la participación cuando sea necesario.

Para reportar un problema de conducta, contacta a los mantenedores mediante las opciones privadas de contacto que ofrece GitHub para este repositorio. Evita publicar detalles sensibles en un issue público.
